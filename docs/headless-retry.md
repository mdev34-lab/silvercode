# Headless retry ceiling contract

- Owner: `SessionRetry` (`packages/opencode/src/session/retry.ts`) and `SessionProcessor` (`packages/opencode/src/session/processor.ts`).
- Default ceiling: non-interactive headless `silvercode run` / `opencode run` turns (including background subagents spawned inside a headless run and `--attach` runs) cap single-attempt provider retry delays at `RETRY_HEADLESS_MAX_DELAY = 60_000` ms (60 seconds). When a provider HTTP 429 `retry-after` / `retry-after-ms` header or computed backoff exceeds that ceiling, the turn fails immediately with the original `APIError` instead of sleeping for multi-hour quota reset windows (#555).
- Interactive modes: the TUI, `silvercode --mini` (`run --interactive`), and non-headless `silvercode serve` requests keep unbounded retry status reporting and mid-retry model switching (`HeadlessRunRef` is `undefined`).
- Experimental override: `OPENCODE_EXPERIMENTAL_RETRY_MAX_DELAY_MS` (`packages/opencode/src/effect/runtime-flags.ts`) accepts a positive integer millisecond value overriding `RETRY_HEADLESS_MAX_DELAY`. It takes effect **only** when `HeadlessRunRef` is active (headless runs) and is ignored in interactive/non-headless sessions. Neither `HeadlessRunRef` nor internal headless markers are exported into child processes spawned by tools.
- HTTP transport & trust boundary: headless `run` propagates its per-request retry context over `x-opencode-headless: 1` and optional `x-opencode-retry-max-delay: <ms>` headers (`packages/opencode/src/effect/instance-ref.ts`). `InstanceContextMiddleware` (`packages/opencode/src/server/routes/instance/httpapi/middleware/instance-context.ts`) binds `HeadlessRunRef` strictly to the current HTTP request fiber (`Option.isSome(HttpServerRequest)`), preserving ambient `HeadlessRunRef` when invoked without an HTTP request. Any client admitted to the instance API (local loopback, or authenticated via `ServerAuth` / `OPENCODE_SERVER_PASSWORD` when exposed on a network) can only tighten/adjust retry waits on its own request turn, never across other sessions or clients.
