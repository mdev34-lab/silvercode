Performs exact string replacements in files.

- Use Read at least once on the file before editing, or the edit errors.
- Preserve exact indentation as it appears AFTER the Read line-number prefix (`<line>: `); never include the prefix in oldString or newString.
- Prefer editing existing files; do not create new files unless required. No emojis unless asked.
- Fails if `oldString` is not found, or is found multiple times: add surrounding context to make it unique, or use `replaceAll` to change every instance (e.g. renames).
